# 영어 단어 플래시카드

서버·데이터베이스·로그인 없이 동작하는 정적 페이지입니다. `flashcards` 폴더를 그대로 홈페이지에 올리면 `/flashcards/` 주소로 열 수 있습니다. 외부 라이브러리, CDN, API를 사용하지 않습니다.

## 교사가 단어와 세트 수정하기

`words.js`만 편집하면 됩니다. 영어 단어와 뜻을 한 쌍으로 추가하세요.

```js
window.FC_SETS = [
  {
    id: "unit1",
    title: "Unit 1 기본 단어",
    words: [
      { en: "apple", ko: "사과" },
      { en: "borrow", ko: "빌리다" }
    ]
  }
];
```

세트의 `id`는 URL에서 사용하는 고유한 짧은 값으로 정합니다. 비어 있는 단어와 같은 세트 안에서 중복된 영어 단어는 자동으로 건너뜁니다. 단어 세트가 여러 개면 첫 화면에서 고를 수 있고, 하나뿐이면 바로 시작합니다.

## 기존 홈페이지에 올리기

1. 이 폴더의 `flashcards` 폴더를 홈페이지 파일에 그대로 복사합니다.
2. 홈페이지에 `/flashcards/` 링크를 추가합니다.
3. 빌드 명령이나 서버 설정은 필요하지 않습니다.

세트별 숙제 링크는 `https://홈페이지주소/flashcards/?set=unit2`처럼 만듭니다.

## iframe 삽입 예시

```html
<iframe
  src="/flashcards/?set=unit1"
  title="영어 단어 플래시카드"
  width="100%"
  height="720"
  loading="lazy"
  style="border:0; border-radius:20px"
></iframe>
```

화면 색은 `style.css` 맨 위의 `--fc-main`, `--fc-accent`, `--fc-paper` 등 CSS 변수에서 바꿀 수 있습니다.

## 학습 기능

- 카드를 누르거나 스페이스/엔터를 눌러 뒤집습니다.
- `알아요`와 `헷갈려요` 버튼 또는 키보드 오른쪽/왼쪽 화살표로 답을 표시합니다.
- 순서대로 보기, 섞어 보기, 영어→한국어, 한국어→영어를 바꿀 수 있습니다.
- 브라우저 음성 합성을 지원하면 영어 발음 버튼이 나타납니다.
- 마지막 결과와 헷갈린 단어는 해당 기기의 localStorage에 저장됩니다. 저장을 막은 브라우저에서는 기록 없이 계속 사용할 수 있습니다.
- 학생 이름이나 개인정보를 입력하거나 저장하지 않습니다.
