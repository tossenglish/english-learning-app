---
name: Word settings save behavior
description: Keep initial-screen word saving usable even when the admin has not preselected or created a word folder.
---

When saving initial-screen word content, select an existing folder for the course automatically; if none exists, create a course-specific word folder rather than failing solely because the folder selector is empty.

**Why:** The primary save action is for initial-screen content, and requiring separate folder setup made the save appear broken even when the entered word and meaning were valid.

**How to apply:** Preserve the selected folder when present. Otherwise choose a matching course folder, then a shared folder, and create a matching root word folder only when no suitable folder exists.
