---
name: Admin home practice
description: Admins should be able to practice assignments they issued from the learner home screen.
---

Administrators need a visible top-bar link to the admin workspace and a home-screen path to open and practice the assignments they issued, not only a way to manage them in the admin area.

**Why:** the user requested that admins can try their own assigned work from the home screen and reported the admin link missing.

**How to apply:** Use an admin-authorized assignment source for the admin home view; do not widen the regular learner assignment endpoint.
