영어 단어 플래시카드 웹페이지를 만들어 주세요. 학생들이 숙제로 단어를 연습하는 용도이고, 이미 운영 중인 학교/학원 홈페이지에 폴더 하나로 추가해서 쓸 것입니다.

## 1. 기술 조건 (가장 중요)
- 서버, 데이터베이스, 로그인이 없는 순수 정적 페이지로 만들어 주세요. HTML, CSS, JavaScript만 사용하고 빌드 과정이 없어야 합니다.
- 파일 구성은 아래처럼 한 폴더 안에 모두 들어가게 해 주세요.
  flashcards/
    index.html
    style.css
    app.js
    words.js   ← 단어 데이터만 들어 있는 파일
    README.md
- 외부 CDN, 외부 API, 외부 폰트를 쓰지 마세요. 시스템 폰트만 사용합니다.
- 기존 홈페이지와 충돌하지 않도록 모든 CSS 클래스 이름 앞에 `fc-` 접두어를 붙이고, `body`, `html`, `*` 같은 전역 선택자는 쓰지 마세요. 전역 변수도 만들지 말고 JavaScript 전체를 즉시실행함수(IIFE)로 감싸 주세요.
- 링크로 연결해도, 다른 페이지 안에 iframe으로 삽입해도 둘 다 정상 동작해야 합니다.
- 화면의 모든 문구는 한국어입니다.

## 2. 단어 데이터 (words.js)
- 교사가 이 파일만 고쳐도 단어가 바뀌도록, 아래 형식으로 만들어 주세요.

  window.FC_SETS = [
    { id: "unit1", title: "Unit 1 기본 단어", words: [
      { en: "apple", ko: "사과" },
      { en: "borrow", ko: "빌리다" }
    ]},
    { id: "unit2", title: "Unit 2 학교 생활", words: [ ... ] }
  ];

- 샘플로 초등 필수 단어 10개씩 두 세트(Unit 1, Unit 2)를 넣어 주세요.
- 세트가 여러 개면 첫 화면에서 세트를 고르게 하고, 하나뿐이면 바로 시작합니다.
- 선택 사항: 페이지 주소에 `?set=unit2`를 붙이면 해당 세트가 바로 열리게 해 주세요. (숙제 링크를 세트별로 나눠 주기 위함)
- words.js의 데이터에 빈 값, 중복, 이상한 형식이 있어도 페이지가 멈추지 않게 하고, 문제가 있는 항목은 건너뛰어 주세요.

## 3. 플래시카드 기능
- 카드 앞면에는 영어 단어, 뒷면에는 뜻을 보여 줍니다. 카드를 누르면 3D 뒤집기 애니메이션으로 뒤집힙니다. (스페이스바, 엔터 키로도 뒤집기 가능)
- 카드 아래에 "알아요" / "헷갈려요" 버튼을 둡니다. 누르면 다음 카드로 넘어갑니다. (키보드: → 알아요, ← 헷갈려요)
- 상단에 진행 상태(예: 3 / 10)와 진행 막대를 보여 주고, "알아요 n개 / 헷갈려요 n개" 개수를 함께 표시합니다.
- 시작할 때 카드 순서를 무작위로 섞고, "순서대로 / 섞기" 전환 버튼을 둡니다.
- "앞면 선택" 설정: 영어→한국어(기본) / 한국어→영어 중 선택할 수 있게 합니다.
- 모든 카드를 마치면 결과 화면을 보여 줍니다.
  - 알아요 / 헷갈려요 개수
  - "헷갈린 카드만 다시 보기" 버튼 (헷갈린 카드가 없으면 숨기고 칭찬 문구 표시)
  - "처음부터 다시 하기" 버튼
- 영어 발음 듣기: 카드마다 스피커 버튼을 두고 브라우저 내장 음성(SpeechSynthesis, 영어 en-US)으로 읽어 줍니다. 이 기능을 지원하지 않는 브라우저에서는 스피커 버튼을 숨겨 주세요. 스피커 버튼을 눌러도 카드가 뒤집히지 않아야 합니다.
- 카드를 한 장 완료할 때마다 가벼운 효과(색 변화, 살짝 튀는 애니메이션)를 넣어 주세요. 소리 효과는 넣지 않습니다.

## 4. 학습 기록 (서버 없이)
- 기기 안(localStorage)에만 저장합니다. 세트별로 "마지막 학습 결과(알아요/헷갈려요 개수)"와 "헷갈린 단어 목록"을 저장하고, 첫 화면에 보여 주세요.
- 다음에 열면 "지난번에 헷갈린 단어만 복습하기" 버튼이 나오게 해 주세요.
- localStorage를 쓸 수 없는 환경(iframe 제한, 시크릿 모드 등)에서도 오류 없이 동작해야 합니다. 읽기/쓰기를 모두 try/catch로 감싸고, 실패하면 기록 없이 계속 진행하세요.
- 이름, 연락처 등 개인정보는 어떤 것도 입력받거나 저장하지 마세요.

## 5. 디자인과 접근성
- 밝고 친근한 분위기로 만들고, 둥근 모서리와 큰 카드를 사용해 주세요.
- 스마트폰 세로 화면(너비 360px)을 기준으로 설계하고 태블릿, PC에서도 보기 좋게 반응형으로 만들어 주세요.
- 버튼은 터치하기 쉽게 최소 44px 높이로, 글자는 카드 단어 기준 28px 이상으로 합니다.
- 색만으로 구분하지 말고 "알아요 ✓ / 헷갈려요 ?"처럼 아이콘이나 글자를 함께 표시하세요.
- 키보드로 모든 기능을 쓸 수 있게 하고, 포커스 표시가 보이게 해 주세요.
- 색상은 CSS 변수(`--fc-main`, `--fc-accent` 등) 몇 개로 모아서, 나중에 기존 홈페이지 색에 맞춰 바꾸기 쉽게 해 주세요.
- 클래스카드, 퀴즐렛 등 다른 서비스의 이름, 로고, 화면 디자인을 따라 하지 마세요.

## 7. 완료 기준
- 샘플 세트 2개에서 카드 넘기기부터 결과 화면까지 끝까지 동작합니다.
- 단어가 1개, 2개뿐인 세트에서도 오류 없이 동작합니다.
- 헷갈린 카드만 다시 보기와 지난번 헷갈린 단어 복습이 동작합니다.
- 너비 360px 화면에서 레이아웃이 깨지지 않습니다.
- 브라우저 콘솔에 오류가 없습니다.
- 작업이 끝나면 직접 실행해서 위 항목을 확인하고, 확인한 결과와 아직 안 되는 부분을 알려 주세요.
