영어 단어 연습 웹앱을 만들어 주세요. 학생들이 숙제로 재미있게 단어를 연습하는 용도이고, 교사가 단어 세트를 직접 만들어 링크로 공유할 수 있어야 합니다.

## 1. 기술 조건 (중요)
- 서버와 데이터베이스가 없는 순수 정적 웹앱으로 만들어 주세요. HTML, CSS, JavaScript만 사용하고, 빌드가 필요 없는 구조(index.html, style.css, app.js)가 가장 좋습니다.
- 나중에 Render의 Static Site로 배포합니다. Replit 전용 설정이나 Replit 전용 서비스에 의존하지 마세요.
- 외부 CDN이나 외부 API 없이 동작하게 해 주세요. 폰트는 시스템 폰트를 사용합니다.
- 다른 홈페이지에 iframe으로 삽입될 수 있으므로, iframe 안에서도 정상 동작해야 하고 반응형으로 만들어 주세요. 스마트폰 세로 화면을 우선으로 설계하고 태블릿과 PC에서도 잘 보여야 합니다.
- 화면의 모든 문구는 한국어로 작성합니다.

## 2. 단어 세트 만들기 (교사용)
- 첫 화면에 "단어 세트 만들기" 영역을 둡니다.
- 텍스트 입력창에 한 줄에 한 단어씩 `영어,뜻` 형식으로 붙여 넣을 수 있게 합니다. (엑셀에서 복사한 탭 구분 형식도 인식)
  예시:
  apple,사과
  borrow,빌리다
- 세트 제목을 입력할 수 있게 합니다.
- 입력 내용을 검사해서 형식이 잘못된 줄은 몇 번째 줄인지 알려 주세요.
- "학생용 링크 만들기" 버튼을 누르면, 단어 세트 전체가 URL의 해시(#) 뒤에 압축/인코딩되어 들어간 링크가 만들어지게 합니다. 서버 저장 없이 링크만으로 같은 세트가 열려야 합니다. 링크 복사 버튼도 넣어 주세요.
- 링크로 접속한 학생에게는 세트 만들기 화면이 보이지 않고 바로 학습 메뉴가 나타나게 합니다.
- 세트를 이 브라우저(localStorage)에 저장하고 불러오는 기능도 넣어 주세요.
- 샘플 단어 세트(초등 필수 단어 10개)를 "예시 불러오기" 버튼으로 제공합니다.

## 3. 학생용 학습 활동 (4가지)
1. **플래시카드**: 카드를 누르면 뒤집혀 뜻이 보입니다. "알아요 / 헷갈려요" 버튼으로 분류하고, 헷갈리는 카드만 다시 볼 수 있게 합니다.
2. **짝 맞추기 게임**: 영어 카드와 뜻 카드를 짝지어 맞추는 게임입니다. 한 판에 6쌍을 사용하고, 걸린 시간과 틀린 횟수를 보여 줍니다.
3. **4지선다 퀴즈**: 영어를 보고 뜻 고르기 / 뜻을 보고 영어 고르기를 선택할 수 있습니다. 오답 보기는 같은 세트의 다른 단어에서 뽑습니다. 단어가 4개 미만이면 보기 수를 자동으로 줄입니다.
4. **철자 쓰기**: 뜻을 보여 주고 영어 철자를 입력하게 합니다. 힌트 버튼(첫 글자 보기)을 제공하고, 대소문자와 앞뒤 공백은 무시합니다.

## 4. 재미 요소
- 정답을 맞히면 점수와 연속 정답 콤보가 올라가고, 짧은 효과(색 변화, 간단한 애니메이션)가 나옵니다.
- 활동이 끝나면 결과 화면에서 점수, 정답률, 틀린 단어 목록을 보여 주고 "틀린 단어만 다시 하기" 버튼을 제공합니다.
- 효과음은 Web Audio API로 간단히 만들고, 소리 켜기/끄기 버튼을 둡니다. 기본값은 꺼짐입니다.
- 단어의 영어 발음을 브라우저 내장 음성(SpeechSynthesis, 영어)으로 들을 수 있는 스피커 버튼을 카드와 문제마다 넣어 주세요. 지원하지 않는 브라우저에서는 버튼을 숨깁니다.
- 단어 순서는 매번 섞습니다.

## 5. 기록과 개인정보
- 학생 이름이나 개인정보를 입력받지 마세요. 필요하면 닉네임(선택 입력)만 사용합니다.
- 최고 기록(활동별 최고 점수, 최단 시간)은 브라우저 localStorage에 세트별로 저장하고, 첫 화면에서 보여 줍니다.
- localStorage를 사용할 수 없는 환경(iframe 제한, 시크릿 모드 등)에서도 오류 없이 동작해야 합니다. 읽기/쓰기는 모두 try/catch로 감싸고, 실패하면 기록 없이 계속 진행합니다.

## 6. 디자인
- 밝고 친근한 느낌으로, 큰 버튼과 큰 글씨(터치하기 쉽게 최소 44px)를 사용합니다.
- 색상만으로 정답/오답을 구분하지 말고 아이콘(O/X)이나 문구도 함께 표시합니다.
- 키보드만으로도 주요 기능을 사용할 수 있게 해 주세요.
- 특정 상용 서비스(클래스카드, 띵커벨, Quizlet, Kahoot 등)의 이름, 로고, 화면 디자인을 따라 하지 말고 독자적인 디자인으로 만들어 주세요.

## 8. 완료 기준
- 샘플 세트로 4가지 활동이 모두 끝까지 동작합니다.
- 생성된 학생용 링크를 새 탭에서 열면 같은 단어 세트로 바로 학습할 수 있습니다.
- 단어가 3개뿐이거나 1개뿐인 경우에도 오류 없이 동작하거나 안내 문구가 나옵니다.
- 모바일 화면(너비 360px)에서 레이아웃이 깨지지 않습니다.
- 작업을 마치면 직접 실행해서 위 항목을 확인하고, 확인한 결과와 아직 안 되는 부분을 알려 주세요.
